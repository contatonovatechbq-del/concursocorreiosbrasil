

# Atualizar faixa salarial para R$ 5.700 a R$ 9.000

Alterar o range de remuneração em 3 arquivos (páginas dos Correios):

1. **`src/pages/DetalhesInscricao.tsx`** (linha 57)
   - De: `R$ 2.400 a R$ 3.000`
   - Para: `R$ 5.700 a R$ 9.000*`

2. **`src/pages/Resultado.tsx`** (linha 140)
   - De: `R$ 2.429,26 + Benefícios`
   - Para: `R$ 5.724,23 + Benefícios`

3. **`src/pages/Index.tsx`** (linha 92)
   - De: `R$ 2.429,26 + Benefícios (VA, VT, Plano de Saúde)`
   - Para: `R$ 5.724,23 + Benefícios (VA, VT, Plano de Saúde)`
